# כתב יד S027 — סדר הוצאה · אתר הערות המגיב

תצוגת HTML של קובץ הבסיס `כתב_יד_S027_P04577_מקור_797_הערות.docx` — **גוף המסמך וכל ההערות בזרימה אחת**:

- **זרימה אחת**: גוף המסמך מוצג כרצף רגיל **ללא מסגרת**, וכל הערה מופיעה מיד **אחרי הפסקה שעליה היא מוסבת** — כך שרואים מיד איזו הערה מתייחסת לאיזה קטע.
- **תיבות הערה מזוהות לפי סוג**: רקע צבוע ומסגרת בגוון הסוג (המסגרת אינה מסמלת חומרה).
- **קטלוג כפול**: כל הערה מסווגת לפי **סוג** (9 סוגים) ולפי **חומרה** (נמוכה / בינונית / גבוהה). החומרה נקבעה בבדיקה עצמאית של תוכן ההערה, בלי להסתמך על ערך החומרה הכתוב בהערה עצמה.
- **סינון**: לפי סוג ולפי חומרה (מקושרי הטקסט מעומעמים כשההערה מסוננת). פאנל «קטלוג» מציג טבלת סוג×חומרה עם סינון בלחיצה.
- **ניווט בין הערות**: כפתורי «הערה הבאה / הערה קודמת» קופצים להערה הבאה בסדר המסמך **גם אם היא בפרק אחר** (קיצורים: Alt+↓ / Alt+↑; פרקים: Alt+← / Alt+→).
- **מצב עריכה** (Alt+E): עריכה ישירה של גוף ההערות ושל פסקאות הגוף; העריכות נשמרות אוטומטית בדפדפן.
- **הורדות**: כל פרק או הפרקים שנערכו — בפורמט **HTML לוורד** (התיבות הצבעוניות נשמרות), **JSON** לשילוב חזרה, או **ZIP** של כל הפרקים הנערכים.
- בוחרים **פרק** בראש הדף; כל פרק נטען מקובץ נפרד (`chapters/chNN.js`); האינדקס הגלובלי ב-`chapters/notes-index.js`.
- 63 פרקים, 1,308 הערות (מתוכן 510 הערות מגיב — שילוב קטעים חסרים).
- ניתן להוריד את התיקייה כולה ולפתוח את `index.html` גם ללא חיבור לאינטרנט.
