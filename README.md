- **קטלוג כפול**: כל הערה מסווגת לפי **סוג** (11 סוגים) ולפי **חומרה** (נמוכה / בינונית / גבוהה). החומרה נקבעה בבדיקה עצמאית של תוכן ההערה, בלי להסתמך על ערך החומרה הכתוב בהערה עצמה.
- **סינון**: לפי סוג ולפי חומרה (מקושרי הטקסט מעומעמים כשההערה מסוננת). פאנל «קטלוג» מציג טבלת סוג×חומרה עם סינון בלחיצה.
- **ניווט בין הערות**: כפתורי «הערה הבאה / הערה הקודמת» קופצים להערה הבאה בסדר המסמך **גם אם היא בפרק אחר** (קיצורים: Alt+↓ / Alt+↑; פרקים: Alt+← / Alt+→).

- **הורדות**: כל פרק או הפרקים שנערכו — בפורמט **HTML לוורד** (התיבות הצבעוניות נשמרות), **JSON** לשילוב חזרה, או **ZIP** של כל הפרקים הנערכים.
