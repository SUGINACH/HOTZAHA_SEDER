# תיעוד הריפו

בתיקייה זו נמצאים מסמכי התיעוד של סידור הריפו:

- `מיפוי_קבצים_ושינויי_שמות.md` - מיפוי מלא של מיקומם החדש של כל הקבצים, ופירוט שינויי השמות של הקבצים הכפולים.

התיקייה הראשית מכילה את הקובץ המעודכן של הספר ואת מסמך הבדיקה "קטעים לבדיקה - האם נמחקו בטעות".
כל יתר הקבצים מסודרים בתיקיות נושא ממוספרות.
